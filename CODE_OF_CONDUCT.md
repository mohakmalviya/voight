# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique ideas rather than people, and do not harass anyone. Maintainers may remove comments, commits, issues or contributors that break these rules.

Report unacceptable behaviour privately to the maintainer through the contact listed on the maintainer's GitHub profile. Reports are handled confidentially.
